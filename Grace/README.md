- Source หลัก: `Agents.gs`, `Main.gs`
- Integration: `Bot3Hub.gs`
- ราคาเทคนิคหลักเป็นแท่งรายวัน ไม่ใช่ realtime
- โปรเจกต์นี้ไม่มี execution ใน 7 วันล่าสุด ณ 29 ส.ค. 2026 จึงต้องติดตั้ง trigger/ทดสอบก่อนถือว่า active
